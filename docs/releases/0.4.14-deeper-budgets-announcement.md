# local-bench 0.4.14 public announcement copy

Owner and signer: Michael.

## Ready-to-use announcement copy (Michael-owned)

local-bench 0.4.14 prepares the deeper generic-thinking operating point. The
current profile, `generic_think_tags_32768_v1`, uses 32768 thinking tokens plus
16384 final tokens (49152 promised generated tokens), a 65536-token server
context, and a 32768-token agentic context. Existing 8k profiles and rows stay
published as historical operating points; cross-profile scores are not
compute-matched.

R3 is decided: at the canonical scored stage of the two-run stability campaign,
the fusion bundle recorded 0.32% agentic length finishes, below the 2% trigger,
with drift at 0.0pp, so per-turn output remains 1024. The 40-turn cap and
65536 cumulative per-task cap are provisional pending R2 PRO 6000 DEV
calibration.

For Qwen35, native context is 262144 and no context extension is used. The
hybrid Qwen35 measurement was 26,574 MiB at ctx 65536 with f16/f16 KV on an RTX
5090. Feasibility is architecture-dependent; dense models may not fit. The CLI
fails closed and offers `generic_think_tags_8192_v1` explicitly rather than
silently lowering context or budgets. Gemma remains on
`gemma4_channel_8192_v1` in this release.

Canonical llama.cpp b10076 launches use `-ctk f16` / `--cache-type-k f16`,
`-ctv f16` / `--cache-type-v f16`, `--fit off`, and explicit
`--flash-attn on|off|auto`. We assert effective runtime state from live
`/props` plus current-process startup evidence when `/props` lacks a field,
not from launch arguments alone.
